# Rodrigo Noya — portfolio v4

Portfolio estático para GitHub Pages.

## Navegación

- Escritorio: rueda del mouse + flechas.
- Teléfono: swipe horizontal para cambiar de pantalla.
- El CV mantiene scroll vertical interno para leer todo el texto.
- Las obras siguen siendo pantallas horizontales.
- En móvil los fondos muestran una mayor porción de la imagen, con fondo desenfocado para completar el formato vertical.
- La fotografía del CV permanece integrada en el lateral.
- Videos se abren en modal de YouTube.
- Menú responsive usa categorías genéricas en lugar de títulos de obras.

## Publicar

Subir `index.html`, `style.css`, `script.js` y `assets/` a la raíz del repositorio.

GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
